# XEO 手柄与多声道回放验证 v0.1.1

> 用 iPhone 测试兼容手柄的扳机输入与触觉，再比较不同输出设备的多声道回放表现。

## 手柄

- 连接 iOS 兼容手柄，查看系统识别名称、控制器类型和可用触觉位置。选中当前手柄后，分别扣动左右扳机，实时查看按下或松开的状态，模拟扳机还会显示行程百分比。左右输入分别判定，系统未提供的一侧单独提示。
- 可在系统报告的握把或扳机位置播放点震、持续振动和三连点。使用原装 DualSense 验证有线触觉，并体验固定扳机振动、随行程递增的振幅和线性阻力。
- 可以立即停止全部效果。离开测试页、切入后台或切换手柄时停止效果。

## 音频

- 播放立体声基准、5.1、7.1 与 Apple 官方 Dolby Atmos 样本。5.1 和 7.1 依次发声，界面指出当前测试哪个声道。
- 对照实际片源编码、声道数，以及 iOS 当前输出设备、当前/最大声道数、系统音频设备格式与空间音频状态。输出设备插拔后刷新诊断。
- 区分多声道硬件输出和双声道空间化。听感、物理声道路由及 Atmos 外部解码由测试者或接收设备确认。
- 支持导入本机测试媒体，复测相同输出设备。

## 通过条件

Debug 版能在连接的 iPhone 上安装和启动。手柄震感、各路发声、空间定位及外设解码以真机测试记录为准。
